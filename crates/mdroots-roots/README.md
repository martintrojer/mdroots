# mdroots-roots

Safe, zero-config root discovery: never lists a tree before it is known to be local and bounded.

This is an internal crate of [mdroots](https://github.com/martintrojer/mdroots)
with no stability promise: its API may change in any release. Depend on
[`mdroots`](https://crates.io/crates/mdroots) (the library) or install
[`mdroots-cli`](https://crates.io/crates/mdroots-cli) (the command line and
language server) instead.
